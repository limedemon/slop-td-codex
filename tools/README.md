# Конвейер сборки Slop TD FAQ

Рабочие скрипты, которыми пересобирается сайт. Живут здесь, а не только в
скратчпаде сессии, чтобы следующая сессия могла обновить данные, не
восстанавливая всё заново.

## Что тут лежит

| Файл | Что делает |
|---|---|
| `refresh_match.luau` | дамп из места катки: юниты, прокачка, лимиты установки, награды за катки, дроп предметов, рецепты крафта |
| `refresh_lobby.luau` | дамп из лобби: ящики, сундуки, спреи, предметы, все мерчанты, пити, пул саммона |
| `build_data.py` | собирает `site_full.json` из двух дампов выше + `icon_map.json` |
| `prep_icons.py` | уменьшает иконки из `C:\Users\Computer\icons_sorted` до 128×128 и раскладывает в `../icons/` с картой имён |
| `hub_tpl.html` | шаблон страницы — вся вёрстка, стили и JS, данные подставляются позже |
| `build_site.py` | склеивает `hub_tpl.html` + `site_full.json` → `index.html` (для сайта) и `slop-codex.html` (для артефакта), проставляет дату сборки |

## Как обновить данные после изменений в игре

1. Открыть Potassium, убедиться что есть хотя бы один клиент в лобби и один
   в катке (`GetPlaceId`: катка `85247278545351`, лобби `134459712190924` —
   могут смениться при обновлении игры, тогда искать заново по наличию
   нужных модулей, см. [references/mining.md](../../../.claude/skills/game-faq-site/references/mining.md)
   в скилле `game-faq-site`).
2. Выполнить `refresh_match.luau` на клиенте в катке, `refresh_lobby.luau` —
   на клиенте в лобби (через `execute_script` / HTTP-обход, см. тот же
   `mining.md`).
3. Скопировать `refresh_match.json` и `refresh_lobby.json` из папки
   `workspace` экзекутора рядом с этими скриптами.
4. Если менялись иконки (новый юнит, новый ящик) — обновить
   `C:\Users\Computer\icons_sorted` и перезапустить `prep_icons.py`.
5. `python build_data.py` — пересобрать `site_full.json`. Диффнуть с прошлой
   версией перед перезаписью (см. `game-faq-refresh`, шаг «сравнить»), чтобы
   не потерять из виду, что именно изменилось.
6. `python build_site.py` — пересобрать `index.html` и `slop-codex.html`.
7. Проверить синтаксис и посмотреть глазами — см. `references/deploy.md`
   скилла `game-faq-site`.
8. `git add -A && git commit && git push`, дождаться что Pages отдаёт
   новую версию, опубликовать артефакт.

Подробный процесс с диффом и типовыми граблями — в скилле
`game-faq-refresh`.
