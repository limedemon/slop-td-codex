# Slop TD Codex

Справочник игрока по Slop Tower Defense. Одна статичная страница без сборки и зависимостей.

## Что внутри

- **Юниты** — 162 штуки: характеристики базовые и максимальные, полная таблица прокачки с ценой каждого уровня, лимит установки на карте, из каких ящиков и пулов саммона выпадают. Поиск, фильтры по редкости и тиру, выбор типа атаки, четыре сортировки.
- **Ящики** — 21 ящик и сундук плюс оба саммона, пити и модификаторы юнита. Для каждой позиции показан процент, шанс вида «1 из N» и редкость.
- **Катки** — 30 режимов с наградой за прохождение, обычные карты и эндлес отдельно.

Интерфейс переключается между русским и английским, выбор запоминается в браузере. Тема светлая или тёмная по настройке системы.

## Запуск

Открыть `index.html` в браузере. Больше ничего не требуется.

## Деплой

Страница публикуется через GitHub Pages из ветки `main`, корень репозитория.

## Правки

Весь код, стили и данные лежат в `index.html`. Данные встроены в страницу объектом `DATA` в конце файла, подписи интерфейса — в объекте `I18N` рядом.
